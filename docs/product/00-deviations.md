# Deviations ledger — spec vs repository

One row per known difference between the product spec in this folder and what the repository
(code, `docs/DECISIONS.md`, `docs/TECH_STACK.md`, `src/ARCHITECTURE.md`) actually does.
Policy (decided 2026-09-06): **the spec wins for product behaviour** (routes, pages,
collections, fields, emails, copy); **recorded decisions win for architecture**. A ticket that
implements a listed line follows the _Resolution_ column. Add a row when you find a new
difference; remove a row when the difference is gone.

Legend — Wins: `spec` (code/docs change to match the spec), `repo` (spec text is amended or
read with this note), `design` (the artboard decides where the spec is silent or split).
